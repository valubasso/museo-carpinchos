# ¿Carpinchos o Capibaras?

Sitio de la muestra del Museo Etnográfico y Colonial «Juan de Garay», Santa Fe.

- Sitio web: https://valubasso.github.io/museo-carpinchos/
- Página estática adaptable a celulares y computadoras.
- Publicación mediante GitHub Pages desde la rama `main`, carpeta raíz.
